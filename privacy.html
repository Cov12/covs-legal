Privacy Policy: Covs Pro Backups

Last updated: October 21, 2026

"Covs Pro Backups" is a private tool used only by Covs Pro to copy encrypted server backups into Covs Pro's own Google Drive. It is not offered to the public.

What it accesses

The app uses the Google Drive drive.file permission, so it can only see and manage files it created itself. It cannot read any other files in your Drive.

How data is used

Backup files are encrypted on the server before upload and are stored only in the account owner's Google Drive. No data is sold, shared with third parties, or used for advertising. Google user data is used only to provide this backup function, in line with the Google API Services User Data Policy, including its Limited Use requirements.

Retention and deletion

Backups are deleted automatically after 30 days. You can revoke the app's access at any time at myaccount.google.com/permissions.
